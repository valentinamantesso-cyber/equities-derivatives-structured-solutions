# Questões

Aqui ficam os questionários de múltipla escolha, organizados por categoria, pra treinar a teoria vista no site.

Cada categoria é uma página com um quiz interativo: você escolhe uma alternativa, o sistema mostra na hora se acertou ou errou, e no final aparece sua pontuação. Dá pra refazer quantas vezes quiser.

- [Exemplo](exemplo.md) — quiz de demonstração, só pra testar o mecanismo.

*Novas categorias vão sendo adicionadas aqui conforme as perguntas forem enviadas.*
