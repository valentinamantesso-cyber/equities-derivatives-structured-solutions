# Questões

Aqui ficam os questionários de múltipla escolha, organizados por categoria, pra treinar a teoria vista no site.

Cada categoria é uma página com um quiz interativo: você escolhe uma alternativa, o sistema mostra na hora se acertou ou errou, e no final aparece sua pontuação e as questões que você errou. Dá pra refazer quantas vezes quiser.

- [Derivativos](derivativos.md) — 13 questões sobre o Guia Básico de Derivativos
- [Opções](opcoes.md) — 18 questões sobre a página de Opções

*Novas categorias vão sendo adicionadas aqui conforme mais conteúdo for publicado.*
